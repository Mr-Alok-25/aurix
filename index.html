How to install

1

Tap Download and wait for the file aurix.apk.

2

Open the file. If Android asks, allow your browser to install apps (Settings > Install unknown apps).

3

Tap Install. If Play Protect warns about an unknown developer, choose Install anyway.

Questions

Why does Android show a warning?

AURIX is not on the Play Store, so Android shows its normal warning for apps installed from a file.

How do I update?

Open the app. If a new version is out, it asks you to update. You can also use Profile > Check for updates. Your favourites and playlists stay.

What does the app collect?

Only anonymous usage counts (screens opened, minutes of music) and crash reports. It never records song names or what you search. You can turn it off in Profile > Privacy & Security.

iPhone or computer?

Android only. On a computer, scan the code above with your phone.
